# Rewraithed Editor

Level tools for the Rewraithed port of Legacy of Kain: Soul Reaver.

## Tools

- [`blender/`](blender/README.md): a Blender add-on to open a unit, edit it, and
  install it into the game from one panel. Start here if you just want to edit levels.

- [`leveldump/`](leveldump/README.md): reads a level `.drm` from the game disc and prints its terrain, portals, intros, morph data and BSP trees; exports OBJ files for Blender.
